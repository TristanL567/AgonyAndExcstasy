## Layer 1 Source Note

Source claim: Shumway documents that CRSP return data omit many economically important delisting returns for firms removed for bankruptcy or other negative reasons (Shumway1997, abstract; p. 327).
Source claim: The paper argues that these missing returns bias portfolio return calculations because investors generally cannot know in advance which stocks must be sold before a surprise delisting (Shumway1997, pp. 327--328).
Source claim: Using over-the-counter price evidence, Shumway shows that omitted delisting returns can be large, especially for performance-related delistings (Shumway1997, abstract; Sections I--II).
Commentary: This source is essential for the data and methodology sections because index backtests around distress must handle delisting returns or risk overstating feasible performance.
Caution: The paper diagnoses CRSP data bias rather than proposing a predictive model, so it feeds data-integrity arguments more than model-selection arguments.
